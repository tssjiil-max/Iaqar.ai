IAQAR AI — النسخة الموحدة متعددة المكاتب — Workflow V5
=======================================================

تخزين الصور والفيديو: Cloudflare R2 عبر Worker. لا تحتاج النسخة إلى Firebase Storage
ولا إلى ترقية مشروع Firebase. فعّل R2 في حساب Cloudflare مرة واحدة قبل النشر.

هذه النسخة تدير دورة العمل كاملة داخل المكتب نفسه:
رسالة خاصة أو مشاركة من واتساب -> تحليل -> طلب عميل/عرض مالك -> مطابقة مرتبة -> متابعة مستقلة لكل مطابقة -> معاينة -> تفاوض -> اتفاقية وساطة -> إغلاق الصفقة.

أهم ما في النسخة:
- عزل كامل للبيانات بواسطة officeId وصلاحيات Firebase Authentication.
- محرك مطابقة يمنع التضارب غير المنطقي ويشرح أسباب المطابقة والتحذيرات.
- نسبة مطابقة مستقلة عن «جاهزية الإغلاق».
- جاهزية الإغلاق المعتمدة: 🟢 عالية جدًا، 🟡 عالية، 🟠 متوسطة، 🔴 منخفضة.
- حالات المطابقة: نشطة، بانتظار رد، موعد معاينة، تفاوض، تمت الصفقة، أُغلقت.
- سجل نشاط ومواعيد متابعة مستقلة لكل مطابقة وصفقة.
- دورة الصفقة: التواصل -> المعاينة -> التفاوض -> اتفاقية الوساطة -> جاهزة للإغلاق -> تمت الصفقة.
- عند نجاح مطابقة واحدة، تغلق المطابقات الأخرى لنفس طلب العميل تلقائيًا بسبب «تمت الصفقة مع عقار آخر».
- عند فشل صفقة، تغلق مطابقتها فقط وتبقى المطابقات الأخرى متاحة للمتابعة.
- أولويات اليوم، صحة الصفقة، الخطوة التالية، والتنبيه عند تأخر المتابعة.
- إشعارات FCM وربط واتساب الرسمي من Meta للاستقبال فقط.
- Android Share Target لإدخال رسائل القروبات يدويًا إلى المنصة.

ثوابت الأمان:
- لا يوجد إرسال واتساب تلقائي.
- مسارات الإرسال الخارجي محظورة برمجيًا.
- لا يوجد whatsapp-web.js أو MacroDroid في التشغيل.
- اسم Worker القديم يتضمن macrodroid فقط للحفاظ على رابط Webhook الحالي في Meta؛ المسار القديم /ingest معطل.
- officeId ليس وسيلة مصادقة؛ كل قراءة أو إجراء تشغيلي يتطلب مستخدمًا مسجلًا وعضوية فعالة في المكتب، بينما ربط Meta يحتاج صلاحية إدارة أو صلاحية التكاملات.

النشر الكامل على Windows:
1) ثبّت Node.js وFirebase CLI وسجّل الدخول إلى Firebase وCloudflare.
2) أكمل أسرار Worker الموضحة في worker/README-AR.txt.
3) من جذر المشروع شغّل deploy-all.cmd.
4) سيجري السكربت فحص JavaScript واختبارات Worker ثم ينشر Worker وقواعد Firestore والفهارس وFirebase Hosting.

الواجهة:
لم يتغير ترتيب أو تصميم الواجهة المعتمد. أضيفت الوظائف داخل «مساحة العمل» والأزرار والتفاصيل الموجودة أصلًا.
تنبيه أمني للنسخة الحالية:
- شغّل setup-platform-admin.cmd مرة واحدة لإنشاء حساب مدير المنصة.
- الدومين العام لا يفتح مساحة أي مكتب.
- العميل والمالك يرفعان الطلب مباشرة بلا حساب.
- الوسيط يبقى بانتظار الاعتماد حتى مراجعة رخصة فال.
