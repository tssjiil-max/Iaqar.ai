الخطوة الخامسة — دائرة الفرصة والصفقة متعددة المكاتب
====================================================

لم يتغير التصميم:
- لم تتغير الصفحة الرئيسية أو الألوان أو الترويسة أو الأيقونتان.
- استُخدمت البطاقات ومساحة العمل الحالية لعرض البيانات الحقيقية.

تم تنفيذ:
1) إلغاء MacroDroid وملفاته وتعليماته نهائياً.
2) إتاحة Embedded Signup لجميع المكاتب بدل office-alqiq فقط.
3) عزل ربط واتساب ورسائله حسب officeId وPhone Number ID.
4) تحليل الرسالة العقارية محلياً دون API ذكاء اصطناعي مدفوع.
5) استخراج: طلب/عرض، نوع العقار، الحي، بيع/إيجار، السعر، المساحة، الغرف، الجوال.
6) حفظ طلب العميل أو عرض المالك داخل المكتب الصحيح.
7) تشغيل المطابقة داخل المكتب نفسه وإنشاء نسبة توافق وأسباب.
8) إنشاء تنبيه للمكتب وإرسال FCM للأجهزة المسجلة.
9) عرض المطابقات والصفقات الحقيقية في مساحة العمل الموجودة.
10) بدء متابعة المطابقة، تحويلها إلى صفقة، وإغلاق الصفقة.
11) استمرار منع أي إرسال واتساب تلقائي أو مدفوع.

متطلبات التشغيل الخارجي:
- اعتماد تطبيق Meta وEmbedded Signup للإنتاج.
- ربط كل مكتب رقمه بموافقته من زر إعدادات المكتب.
- إضافة Firebase Web Push VAPID public key لتفعيل FCM على المتصفح.
- وجود تسجيل دخول وصلاحيات للمكاتب قبل الإطلاق العام لضمان عدم انتحال officeId.

القروبات:
- لا تُقرأ عبر WhatsApp Cloud API الرسمي في هذا الإصدار.
- المنصة تستقبل الرسائل الخاصة الرسمية فقط.
