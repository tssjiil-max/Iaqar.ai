## حدود التغطية وبوابات الدمج

- لم تُختبر رحلات Meta أو واتساب أو الخدمات الخارجية الحقيقية أو بيانات الإنتاج.
- صفحة الإدارة صُورت عند تسجيل الدخول؛ لم تُختبر كل حالات وحدة التحكم خلف صلاحية مدير المنصة. الواجهة القديمة أظهرت حالة تعذر بدء المنصة محليًا؛ لا تدّعي هذه الدفعة إعادة بناء كل شاشاتها المحمية.
- حزمة e2e القديمة أخفقت في `Party link in a clean context skips Access Gate and broker login` بسبب فشل DNS لخادم Worker، وفي `collapsed match shows identity, type, district, city, price, and reference`. أُعيدت محاولة الاختبار الأول على القاعدة الأصلية وفشل أيضًا؛ إعادة عزل اختبار المهام القديم لم تنتج تقرير إكمال موثوقًا في هذه البيئة. لا نُصنّف الاختبار الثاني ناجحًا ولا نُخفيه.
- يلزم نجاح/تفسير هذين الفحصين، ومعاينة الشاشات المحمية واعتماد المقارنة البصرية، قبل الدمج والنشر التجريبي.
- لم يتم دمج الفرع أو نشره على Staging أو Production.
