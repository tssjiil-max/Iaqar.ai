استخراج ملف مفتاح خدمة Firebase JSON
====================================

لا يحتاج هذا الملف إلا مرة واحدة أثناء النشر.

1) افتح Firebase Console.
2) اختر المشروع: aqar-b5d76.
3) افتح إعدادات المشروع Project settings.
4) افتح تبويب Service accounts.
5) اختر Generate new private key.
6) أكد الإنشاء، وسيتم تنزيل ملف JSON على اللابتوب.
7) عند تشغيل worker/start-deploy.cmd اسحب ملف JSON إلى نافذة PowerShell.

تحذير أمني:
- لا ترفعه داخل الموقع.
- لا ترسله في واتساب أو البريد.
- لا تضعه داخل مجلد public.
- بعد رفع القيم إلى Cloudflare Secrets يمكنك حفظه في مكان آمن خارج مجلد المشروع.
