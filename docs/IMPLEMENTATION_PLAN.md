## 0. تدقيق المستودع (المرحلة 0)

### 0.1 البنية والمكدس — REAL AND CONNECTED

- Firebase Hosting ثابت بلا خطوة بناء (`firebase.json`، إعادة توجيه `/o/**`).
- Firebase Auth: دخول جوال المكتب عبر Custom Token (`POST /auth/phone-login`
  في `worker/src/index.js` + `access-gate.js` loginForm)؛ منصة الإدارة بالبريد.
- Firestore مع قواعد عزل `offices/{officeId}` (`firestore.rules`).
- FCM عبر `fcm-fid.js` (FID أولًا) + `firebase-messaging-sw.js` + مسارات `/fcm/*`.
- Cloudflare Worker + R2 (`wrangler.toml` binding `IAQAR_MEDIA`).
- PWA manifest + share target + أيقونات.
- 40 اختبار Worker (`worker/test/worker.test.mjs`) كلها ناجحة عند التدقيق.

### 0.3 مخاطر أمنية مرصودة

- لا أسرار في المستودع (تم الفحص: لا مفاتيح خاصة؛ `apiKey` العام فقط داخل
  `access-gate.js` من `firebase.app().options` وهو سلوك Firebase Web الطبيعي).
- `devices` و`whatsapp_accounts` مغلقة للعملاء — جيد.
- المجموعة العامة `offices/{officeId}/{anyCollection}` تتطلب `officeId` مطابقًا —
  جيد، لكنها تسمح بمجموعات جديدة بلا تحقق مخطط؛ سيُشدد عند إضافة كيانات جديدة.
- صور base64 مضمنة ~333KB في `index.html` — عبء أداء، ليس خطرًا أمنيًا.

## 2. تسليمات المرحلة 1 (منفذة)

- فتح الإعدادات من الشعار **والغلاف** (الغلاف يظهر في البطاقة عند وجود `coverUrl`).
- لا زر «إعدادات المكتب» ظاهر؛ شارة تحرير خفيفة على الشعار مع aria-label.
- رفع الشعار (`POST /media/office-logo` → R2 `office-logos/{officeId}/logo`).
- سير صور كامل: رفع/معاينة/قص/استبدال/إزالة/حفظ + تحقق نوع وحجم + حالات تحميل وخطأ.
- قص عريض بنسبة قابلة للضبط (`OFFICE_DESIGN.coverCrop` في `office-utils.js`)،
  افتراضي عريض مناسب لواتساب دون تثبيت أبعاد منصة خارجية.
- حقول المكتب: الاسم، الوسيط، الرخصة، المدينة، الجوال (لا حقل بريد — لم يوجد أصلًا).
- تحقق ≥4 أحرف + تفرد مطبّع نظاميًا (معاملة + قاعدة + فحص توفر مسبق).
- رابط المكتب: نسخ + مشاركة أصلية + QR داخل الإعدادات + معاينة الرابط العام.
- تفضيلات إشعارات لكل مكتب (6 أنواع) محفوظة في وثيقة المكتب.
- مدخل «بنك الفرص» داخل الإعدادات يفتح عرضًا حقيقيًا (owners/clients) مع
  تاريخ الإضافة وحالة التعاون فقط.
- نمط «السماح بالتعاون الذكي بين الوسطاء»: تعطيل/موافقة لكل طلب (افتراضي)/تلقائي.
- قواعد Firestore محدثة للحقول الجديدة (enum + خريطة bool + طول URL).
- اختبارات: `tests/office-utils.test.mjs` + إضافات `worker/test/worker.test.mjs`.
