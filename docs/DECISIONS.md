# IAQAR.AI Decisions

## 2026-08-04 — Project constitution adopted

The master directive is treated as mandatory project governance. Future implementation must read the constitution, architecture, and implementation plan before making changes.

## 2026-08-04 — Preserve current stack

Decision: keep Firebase Auth, Firestore, Firebase Hosting/PWA/FCM, Cloudflare Worker, and existing storage binding.

Reason: the repository already uses this architecture and the directive forbids migrations without owner approval.

## 2026-08-04 — Office Settings entry points

Decision: Office Settings opens from the office logo and office cover/display image only.

Reason: the directive explicitly forbids a visible standalone settings button.

## 2026-08-04 — No visible deals page

Decision: remove the visible deals tab and PWA deals shortcut. Internal deal/workflow records may still appear as actionable Operations Center items when generated by backend workflows.

Reason: the directive forbids a separate Deals/الصفقات page while allowing completion badges, operations, and internal states.

## 2026-08-04 — Phase 1 Opportunity Bank entry is minimal

Decision: add a private Office Settings entry that reads current office opportunities only. Full bank editing, sharing, archiving, scoped sharing, and cooperation controls remain Phase 3/6 work.

Reason: Phase 1 requires an entry named "بنك الفرص"; full bank functionality is explicitly assigned to later phases.

## 2026-08-04 — Integration honesty

Decision: do not claim WhatsApp or Telegram production outbound messaging is working. Existing worker behavior blocks outbound message routes.

Reason: production sending requires credentials, webhook validation, delivery/error handling, and integration tests.
