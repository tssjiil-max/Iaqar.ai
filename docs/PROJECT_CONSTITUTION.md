## ما هو IAQAR.AI؟
IAQAR.AI ليس موقعًا عقاريًا عامًا.  
IAQAR.AI هو نظام تشغيل ذكي للمكاتب العقارية والوسطاء المرخصين.

## القاعدة العليا للمنتج
> **النظام يعمل في الخلفية. الوسيط يرى فقط الإجراء المطلوب التالي.**

---

## القواعد الثابتة

### الصفحة الرئيسية — المحتوى المعتمد فقط
الصفحة الرئيسية تحتوي فقط على:
1. **بطاقة المكتب** (Office Card)
2. **إضافة فرصة** (Add Opportunity)
3. **مركز العمليات** (Operations Center)

**محظور إضافته:**
- شريط تنقل سفلي
- صفحة صفقات منفصلة
- زر إعدادات مرئي مستقل
- أي قسم دائم غير معتمد

### بطاقة المكتب
- تفتح الإعدادات عند الضغط على **شعار المكتب** أو **صورة الغلاف**
- لا يوجد زر "إعدادات المكتب" مرئي مستقل
- كلا عنصري الشعار والغلاف لهما نقاط ضغط متاحة

### إعدادات المكتب
تحتوي على الأقسام المعتمدة:
- الهوية البصرية (الشعار، صورة الغلاف، الغلاف الواسع)
- بيانات المكتب (بدون حقل البريد الإلكتروني)
- اسم المكتب الفريد (4 أحرف دنيا، لا تكرار بعد التطبيع)
- رابط المكتب (نسخ + مشاركة + QR)
- تفضيلات الإشعارات (حسب النوع)
- بنك الفرص (مدخل)
- إعدادات التعاون الذكي

### عزل البيانات
- كل سجل مرتبط بـ officeId
- لا مكتب يمكنه قراءة بيانات مكتب آخر
- التعاون عبر سجلات صريحة ومعتمدة فقط
- قواعد Firestore تُطبق العزل — الإخفاء الواجهي وحده غير كافٍ

### اسم المكتب الفريد
- 4 أحرف دنيا من الأحرف الفعلية
- فريد على مستوى النظام بعد التطبيع
- التطبيع: إزالة المسافات والرموز، تحويل للأحرف الصغيرة
- التحقق في قاعدة البيانات بمعاملة لمنع الازدواجية
- قاعدة Firestore تمنع الازدواجية حتى عند التزامن

### نزاهة الميزات
ميزة "تعمل" فقط عندما:
- مسار الكود متصل
- البيانات محفوظة بشكل صحيح
- التحكم في الوصول مُطبق
- الاختبارات الآلية تنجح
- سيناريو القبول يمر
- لا مسار إنتاجي يعتمد بيانات وهمية

### التكاملات الخارجية (WhatsApp / Telegram)
لا تدّعِ أن التكامل كامل بدون:
- بيانات اعتماد صالحة
- Webhooks مُعدّة ومتحقق منها
- معالجة التسليم والأخطاء
- اختبارات تكامل حقيقية

عند غياب البيانات: بناء محوّل نظيف ومحاكاة محلية وتسمية الحالة بـ "adapter ready" أو "simulated".

## التقنيات المعتمدة
- Firebase Authentication
- Firestore
- Firebase Cloud Messaging
- Firebase Storage / Cloudflare R2
- Cloudflare Worker (backend)
- PWA
- واجهة عربية RTL موبايل أولاً

**محظور:** الانتقال لإطار عمل أو قاعدة بيانات أو خدمة استضافة مختلفة بدون موافقة صريحة.
