## تفاصيل تحقق المرحلة 1

### TEST 1 — وصول إعدادات المكتب

- `button#officeSettingsBtn` (الشعار) → يفتح `#officeSettings`.
- `button#officeCoverSettingsBtn` (الغلاف) → يفتح `#officeSettings`؛ يظهر عند
  وجود `coverUrl` فقط حتى لا يتغير الشكل المعتمد بدون غلاف.
- لا يوجد أي زر منفصل باسم «إعدادات المكتب»؛ الشارة على الشعار رمز تحرير فقط
  مع `aria-label` ودعم لوحة المفاتيح عبر `<button>`.

### TEST 3 — اسم المكتب

- `< 4 أحرف دالة` ⇒ رسالة عربية ورفض (واجهة + قاعدة + Worker).
- مكرر بعد التطبيع (NFKC، حالة صغيرة، إزالة مسافات/`.`,`_`,`-`) ⇒ `OFFICE_NAME_TAKEN`
  من المعاملة الذرية؛ الفحص المسبق عبر `/office/name-availability`.
- الفريد يُقبل ويُحفظ مع `officeNameKey` جديد وتحرير الحجز القديم.
- التسابق: حجز `officeNameClaims/{nameKey}` داخل نفس المعاملة ⇒ مستحيل عمليًا أن
  يحصل مكتبان على المفتاح نفسه.

### TEST 15 — صدق الإنتاج

- `worker/README` و`/health`: `mode: inbound-only`, `outboundMessaging: false`.
- بطاقة واتساب في الإعدادات: «يستقبل الموقع الرسائل الخاصة الواردة فقط».
- تيليجرام: غير منفذ — سيُوسم «adapter ready» عند المرحلة 7.
