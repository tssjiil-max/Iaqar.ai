# ربط مؤشر الجاهزية بمكتب كلاود — عقد تجريبي غير منشور

المصدر: `listing-readiness/office-bridge.mjs` في مستودع Iaqar.ai.
مكتب كلاود (MKTB-Cloud) وmktb.cloud مستقلان عن Iaqar.ai. لا تشارك قواعد البيانات أو مفاتيح Firebase أو رموز المالك.

## ما تم
- واجهة محلية `assessLocal(listing)` لا تحتاج شبكة.
- واجهة `assessRemote(listing)` اختيارية ترسل **ملخصًا محدودًا** بعد تقييم محلي إلى:
  `POST {baseUrl}/api/v1/offices/{officeId}/listing-readiness`
- تمرير access token عبر `getAccessToken` من جلسة المستخدم؛ لا تخزين للرمز في الكود أو ملف إعدادات.
- لا تقبل `officeId` القادم من الإعلان؛ يتم تحديده من سياق المكتب المصادق عليه.
- مفتاح إعادة محاولة ثابت لنفس السجل والنتيجة. **يلزم أن يطبق الخادم idempotency فعليًا**؛ المفتاح وحده لا يمنع التكرار.
- لا يرسل نص الإعلان الخام أو الأرقام أو جهات الاتصال.

## ما لم يتم
- هذا المسار **عقد مقترح** وليس عنوان API موثقًا موجودًا في MKTB-Cloud؛ لا تدّعِ أن خادم مكتب كلاود يدعمه حاليًا.
- لم يجر نشر أو فحص اتصال حي أو ربط شاشة أو اختبار صلاحيات فعلي.
- لا يجوز استخدام رمز `radarIngest` لهذه الواجهة؛ ذلك الرمز خاص باستقبال الرادار، وليس بهوية موظف المكتب.

## الاستمرارية بعد تحديث التطبيق
1. احفظ إعدادات الربط غير السرية (معرّف المكتب، إصدار العقد، عنوان الخدمة) **على الخادم** مرتبطة بهوية المستخدم والمكتب، لا في ذاكرة الشاشة أو إصدار APK.
2. عند كل تشغيل، حمّل الإعدادات من مصدر موثوق بعد تسجيل الدخول، ثم أنشئ المحوّل؛ لا تجعل ترقية التطبيق تنشئ ربطًا جديدًا.
3. خزّن أسرار الربط/التجديد في مخزن أسرار آمن وفق النظام، مع تدويرها وإبطالها عند الفصل، ولا تنسخها إلى Iaqar.ai.
4. طبّق على خادم MKTB-Cloud نقطة API صريحة وتحققًا من JWT وRBAC وofficeId وidempotency، ثم اختبر تكاملًا بين المستودعين قبل تفعيل الواجهة.
5. عند تغيير API استخدم إصدارًا جديدًا (v2) مع فترة توافق، ولا تحذف v1 قبل ترحيل الأجهزة.
6. أضف اختبار ترقية يحافظ على نفس officeId والهوية دون فقدان الربط؛ واختبار إلغاء التفويض.
7. افصل الربط مع mktb.cloud عن ربط الرادار الموجود؛ الرادار يستمر في `radarIngest` وصندوقه المستقل.

## اختبار محلي للمكوّن
`node --test listing-readiness/*.test.mjs`

**قرار النشر:** غير جاهز للنشر؛ يحتاج تنفيذ الطرف الخادمي والتكامل والتحقق من صلاحيات المستخدم.
