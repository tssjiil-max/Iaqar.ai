# Iaqar.ai

مكاتب عقارية ذكية — نظام معالجة رسائل واتساب.

## الفكرة الأساسية

- الموقع يقرأ رسائل واتساب (والقنوات الأخرى)، يدرجها في قائمة، يطبعها، ويصنع نسخة منها.
- يمكن تحويل الرسالة إلى **المالك** أو **العميل** أو **الوسيط**.
- إذا وُجدت نسخة لنفس نوع العرض في **نفس الحي**، يُرسل رد بسيط وتنتهي الرسالة.
- الوسائط تتعاون بين القنوات بحسب نوع المحتوى (صورة، صوت، مستند، موقع).

## التشغيل

```bash
npm install
npm run dev
```

- الواجهة: [http://localhost:3000](http://localhost:3000)
- صندوق الرسائل: [http://localhost:3000/inbox](http://localhost:3000/inbox)

```bash
npm run test:logic
npm run build
```

## واجهة البرمجة

- `GET /api/messages` — قائمة الرسائل
- `POST /api/messages` — إدخال رسالة جديدة (أو `{ "reset": true }` لإعادة التعيين)
- `GET /api/messages/:id` — تفاصيل + نص قابل للطباعة
- `PATCH /api/messages/:id` — `{ "action": "copy" | "print" }`
